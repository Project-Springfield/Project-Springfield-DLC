# The event-restore formula (and how the tool matches it)

Derived from the Project-Springfield-DLC event PRs (Easter 2014 `44bb966`,
St. Patrick's `7fd735b`) + the live DLC tree on `E:\SIMPSONS\dlc`. Two things ship
an event: **(1) gamescripts edits** (in the served `gamescripts-r*.zip` pack) and
**(2) DLC pack re-indexing** (in the served `DLCIndex`). EA *drops* an event's
content when it retires; restoring = putting it back. Nothing here patches the APK
or the server — it's all served DLC (base tree + overlay + index).

> **Base matters.** The PS-DLC PRs work from an *older* base pack, so they must ADD
> the event's master-list registrations. Our `E:\SIMPSONS` base is the **full 4.69
> cumulative** pack — it already lists `Superheroes_Buildings`, `Superheroes_Quests`,
> `Superheroes_SpecialEvents`, the 2015 `Superheroes*` dates, etc. So on our base the
> registration step is already done; restore = **enable + reindex**.

## A. Register content in the global master lists
Add `<Include path="<Event>_X.xml:...:MasterList"/>` to each global list:
`buildingmasterlist.xml` (Buildings + Decorations), `charactermasterlist.xml`,
`characterskinmasterlist.xml`, `consumablemasterlist.xml`, `jobmasterlist.xml`,
`spendablemasterlist.xml`, `buildingcontrollers.xml`, `questpackages.xml`
(`<Event>_Quests`), `specialeventlist.xml` (`<Event>_SpecialEvents`).
→ **Tool:** not needed on the 4.69 cumulative base (already present). `undeprecate`
flips the SpecialEvent registry entries from deprecated→active.

## B. Dates / activation
- `dates.xml`: `<Include path="<Event>_Dates.xml:Dates"/>` (already present on our base).
- `<Event>_gameconfig.xml` `<Dates>`: Start/End set to the restore window.
- Main `SpecialEvent` made the *running* event via a `triggerEvent` time requirement.
→ **Tool:** `always_on` (opens every date window 2000→2099) + gameplayconfig
sub-key overrides + `trigger_event`. ✅
- **Act boundaries.** Multi-act events name boundaries `<Event>PartOne..PartFour`.
  `always_on` would send all of them to the far past, but the **last** boundary
  doubles as the prize track's `time end=` cutoff — in the past it disables the
  event's prize currencies + prize lists (the trophy opens a permanent track like
  Monorail). `date_rewrite.force_last_phase_future` keeps the highest-numbered
  boundary in the far future, so the prize track stays active and progresses by
  **quest**, not calendar. ✅ (Applied in BOTH `build_restore` and
  `emit_event_overlay` — dates.xml is rewritten in both.)

## C. Store
- `StoreMenu_Temp_<Event>.xml` — the store section (`StoreMenuIncludes > Categories`
  / `Objects` / `Buildings` …).
- `mainstoremenu.xml` + `storemenu_includes.xml` (our base: `storemenu.xml`): add
  `<Include path="StoreMenu_Temp_<Event>.xml:StoreMenuIncludes:..."/>` each gated by
  `<Requirement type="reqList" location="<Event>_Requirements:StoreCategory_Unlocked"/>`.
- `<Event>_requirements.xml`: the `StoreCategory_Unlocked` reqList + gates.
- `autogenerated_store_<lang>_*` — per-language store copies (16 languages).
→ **Tool:** `store` builder authors `StoreMenu_Temp_<Event>.xml` + includes it into
  `storemenu.xml`. ✅ **Gap:** single language only — no per-language
  `autogenerated_store_<lang>_*` generation yet.

## D. Event's own scripts / config ("the rest")
`<Event>_scripts.xml`, `_quests.xml`, `_requirements.xml`, `_menuconfig.xml`,
`_gameconfig.xml`, `_notifications.xml`, `_skins.xml`, `_jobs.xml`, … — already in
the pack; enabled by A/B. Hand edits land here.
→ **Tool:** `file_edits` (the event's ~41 codename-matched XMLs, editable). ✅

## E. DLC packs — re-index what EA dropped (art / menu / audio / splash)
On retire EA removes the event's packs from the cumulative index; the **files stay
in the served tree**. Re-add a `<Package>` for each (`IndexFileCRC` = CRC32 of the
pack's inner member `0`, `LocalDir=dlc`, served from base). Per event, by tier:
- `<Event>Game-{100,50,25}` — in-town art quality tiers.
- `<Event>Menu-{ipad,ipad3,iphone,retina}` — **menu art** tiers (e.g. `SuperheroesMenu-ipad3`).
- `<Event>Game_LTD-*`, `<Event>Menu_LTD-*` — limited-time art.
- `<Event>Audio-{caf,mp3,wav}`.
- **Splash:** the engine loads the running event's title splash from an
  **event-named** bundle `<event>preload` (e.g. `superheroespreload`), whose
  `splashscreen.xml` is a `<Rulesets>` layering `Background splashscreen.rgb` + the
  event's character graphics. EA's `SuperheroesPreload` (2016) references
  `SS_RadioactiveMan/SS_Falloutboy/MattSig/LANG_TAPPEDOUT.rgb` — art that 2015 never
  shipped — so a naive reindex points at missing graphics.
→ **Tool:** `splash` builds a **self-contained** `<Event>Preload-r<rev>.zip`
  (source_dir `<event>preload`) from the extractor art — authored `splashscreen.xml`
  (Background + lang logos, bundled-art-only) + `splashscreen.rgb` + `lang_*.rgb` —
  in the event's overlay component, indexed (`_build_event_preload_pack`). No
  external-art dependency. Falls back to re-adding an existing `<codename>Preload`
  pack when no extractor art is set. `art_reindex` re-adds `*_LTD-*` art. ✅

## F. Index revision bump
Bump `gamescripts-r<rev>` (filename + `IndexFileCRC` + sizes) so the client
silently re-pulls. Textpools are bumped only when localization changes (separate PR).
→ **Tool:** `_update_index_package`. ✅ (textpools not touched — single-language.)

## G. Legacy-on-modern correctness fixes (beyond A–F)
A/B/E get the event *running*; these make legacy content *work* on the modern
client. They're always-on (or per-event data edits), not part of the original PR
formula. Full worked examples + diagnosis → `SUPERHEROES_RESTORE.md`.
- **Buildings buyable + un-gated** — strip `<Unique value="true">`
  (`_make_event_buildings_buyable`) AND the SpecialEvent `<Buildings override>`
  quest-started `<VisibilityRequirements>` (`_ungate_building_visibility`), or the
  "Build X" quest objective has no store target. Always-on.
- **Null-read crashes** — legacy XML the modern client reads more strictly now:
  - `createobject … onThisObject="true"` → null spawn pos → `atoi(null)` SIGSEGV
    (opt-in `neutralize_spawns`, or remove the cosmetic spawn per-event).
  - a type-34 ProgressDisplay (e.g. `MinibossHealthDisplay`) missing `timerEndTime`
    → `strlen(null)`; add a `timerEndTime` pointing at a past date (timer hidden).
- **Friend spawns** — friend-visit criminal tiers gated too high (5/10/15);
  lower so fresh friends qualify (per-event).
→ **Diagnose** with `adb` tombstone (check `memory near x*` for the parsed XML)
  + the scarlett IDA db (4_69 arm64, base 0x0). Cross-check EA's re-run event.
→ **Where they live:** general fixes = transforms in `restore.py`; per-event data
  fixes = the event's `xmls/` working copy (flow through Build + Stage Prod via
  `file_overrides` — which the transforms source-from / write-back, or the working
  copy clobbers them).

## Tool transform ↔ formula
| Formula | Transform | Status |
|---|---|---|
| A registrations | `undeprecate` (+ base already has them) | ✅ |
| B dates/trigger/gameconfig | `always_on`, `trigger_event`, gameplayconfig | ✅ |
| C store | `store` | ✅ (single-lang; per-lang ✗) |
| D event scripts | `file_edits` | ✅ |
| E art/menu reindex (all tiers) | `art_reindex` (`_LTD`) | ✅ |
| E splash | `splash` (`<Event>Preload`) | ✅ |
| F revision bump | `_update_index_package` | ✅ |
| G buildings buyable/un-gated | `_make_event_buildings_buyable`, `_ungate_building_visibility` | ✅ (always-on) |
| G prize-track act date | `force_last_phase_future` | ✅ (always-on) |
| G null-read crashes | `neutralize_spawns` (opt-in) + per-event data edits | ✅ |

## Known gaps to tool later
1. **Per-language store** (`autogenerated_store_<lang>_*`) — currently single-language.
2. **Reindex breadth** — only `_LTD` (art) + `Preload`/`Splashes` (splash). Fine while
   non-LTD packs stay indexed on our base; revisit if a leaner base drops them.
